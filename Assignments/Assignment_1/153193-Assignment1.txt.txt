1) What is the relative unit in CSS?
	a)Explain what each CSS unit refers to (i.e., what it is relative to):
		em = Relative to the font-size of the parent element.
		rem = Relative to the font-size of the root(<html>) element.
		% = Relative to the parent element`s size.
		vh = 1% of the viewport`s height.
		vw = 1% of the viewport`s width.
		vmin = 1% of the smaller side of the viewport.
		vmax = 1% of the larger side of the viewport.
	
		
	b) Calculate the pixel values given:
		Root(<html>) font-size = 18px 
		Parent element font-size = 22px
		Parent container width = 550px
		Viewport size = 1440px x 900px

	        em = 22px * 1.8em = 39.6px
		rem = 18px * 2.5rem = 45px
		% = 500px * 60% = 300px
		vh = 900px * 0.01 * 7vh = 63
		vw = 1440px * 0.01 * 8vw = 115.2
		vmin = 900px * 0.01 * 6vmin = 54
		vmax = 1440px * 0.01 * 6vmax = 86.4

2) Explain the difference between these two boxes and determine what happens to total box size of

.box1:
