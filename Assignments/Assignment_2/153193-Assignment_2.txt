	}

1. What will be the final value of total after the code executes?
Answer:
  it:
  	1: j = 3-->4, total = 5 * 3 = 15; 
  	2: j = 4-->5, total = 15 + 4 = 19; 
  	3: j = 5-->6, total = 19 * 5 = 95; 
  	4: j = 6-->7, total = 95 + 6 = 101;
  	5: j = 7-->8, total = 101 * 7 = 707;
  	6: j = 8-->|, total = 707 + 8 = 715;

2. What is the purpose of the condition j % 2 === 0 in this code?
Answer: This condition uses modulo. It checks if the iteration-number is a even number.
